# TrackNet: A Deep Learning Network for Tracking High-speed and Tiny Objects in Sports Applications

- 저자: Yu-Chuan Huang, I-No Liao, Ching-Hsuan Chen, Tsì-Uí İk, Wen-Chih Peng
- 발표: AVSS 2019
- 논문: https://arxiv.org/abs/1907.03698
- 코드: 공식 V1 코드 확인 안 됨

## 한 줄 요약
스포츠 중계 영상에서 작고 빠르게 움직이는 공을 추적하기 어려운 문제를 해결하기 위해, 연속된 프레임을 입력받아 공의 위치를 히트맵(Heatmap)으로 예측하는 방법을 제안한다.

## 해결하려는 문제

- **배경:** 공의 궤적 데이터는 선수 평가와 경기 전략 분석에 중요한 기초 정보다.
- **문제:** 공은 크기가 작고 이동 속도가 매우 빨라 영상에서 흐릿하게 촬영되거나 정확한 위치를 파악하기 어렵다.
- **대상 영상:**
    - 주요 대상은 테니스 중계 영상이다. 공이 작고 흐리며, 잔상(afterimage)이 남거나 아예 보이지 않는 경우도 있다.
    - 확장 실험으로 배드민턴도 다룬다.
    - 방송 영상뿐 아니라 스마트폰 같은 일반 기기로 찍은 영상도 대상으로 말한다.
- **기존 방법의 한계:**
    - 상용 시스템(Hawk-Eye 등)은 고해상도·고프레임 영상, 전문 카메라 및 운영 인력이 필요해 구축 및 운영 비용이 높다.
    - 작은 공이 색상이나 형태가 비슷한 물체와 혼동되어 오검출(False Positive)이 발생할 수 있다.
    - 공의 빠른 움직임으로 모션 블러가 발생해 공을 탐지하지 못하는 미검출(False Negative)이 발생할 수 있다.
    - 형태, 색상, 크기 또는 HOG, SIFT 등의 외형 특징에 의존하는 방법은 모션 블러와 잔상이 발생하면 인식 정확도가 떨어진다.
    - 기존 궤적 기반 방법은 프레임별로 찾은 공 후보를 궤적 모델이나 파티클 필터 등 규칙 기반 기법으로 연결한다. 논문은 이를 대체해 궤적 패턴을 학습하는 방식을 제안한다. 
- **이 논문의 목표:** 단일 프레임의 공 이미지 인식뿐 아니라, 연속 프레임에서 공의 궤적 패턴까지 딥러닝으로 학습해 공의 위치를 정확하게 추정한다.
- **가정:** 코트에 공은 최대 1개라고 가정한다.

## 문제 정의

- **Input:** 연속된 프레임. 입력 프레임 수는 네트워크 설정값이며, 논문에서는 1장 모델(Model I)과 연속 3장 모델(Model II)을 구현해 비교했다. (4장)
    - 원본 1280x720 프레임을 640x360으로 리사이즈해 사용한다. (5장)
    - 3장 모델은 연속된 3프레임을 입력받아 마지막 프레임의 공 좌표를 예측한다. (5장)

- **Output:** 입력 프레임과 같은 해상도의 히트맵 1장 (4장)
    - **정답 히트맵:** 공 중심에 2D 가우시안 분포를 배치한다. 분산은 σ²=10이며, 값의 범위는 0~255다. (4장)
    - **모델 출력:** 각 픽셀은 0~255 범위의 grayscale 값을 가진다. (4장)
    - 모델은 히트맵을 출력하며, 공 좌표는 별도의 후처리로 계산한다.
    - 네트워크의 마지막 층은 픽셀마다 256단계(0~255)의 확률을 내고, 그중 가장 높은 값을 고른 것이 히트맵이 된다. (4장, 표 II)

- **Task:** 각 프레임에서 공의 (x,y) 좌표를 추정한다.
    - **후처리 (4장)**
        1. 히트맵을 임계값 128로 이진화한다. (128 이상이면 255, 미만이면 0)
        2. 이진 히트맵에 Hough Gradient Method를 적용해 원을 찾는다.
        3. 원이 정확히 1개 발견되면 원의 중심을 공 위치로 반환한다. 그 외에는 공이 검출되지 않은 것으로 처리한다.

- **Assumption / Limitation:**
    - 코트에 공은 최대 1개라고 가정한다. (서론)
    - 원이 정확히 1개가 아니면(0개이거나 2개 이상) 검출 실패로 처리한다. (4장)
    - 임계값 128은 0~255 히트맵을 이진화하는 기준이다. 평균 공 크기가 약 5픽셀이라 정답 가우시안을 σ²=10으로 만들었고, 그 가우시안에서 값이 128 이상인 영역이 공 크기와 대략 대응한다는 점을 근거로 정했다. (4장)

### WASB와 비교

- **출력 구조:**
    - TrackNet Model II: 연속 3프레임 입력 → 마지막 프레임의 히트맵 1장 출력 (서론, 5장)
    - WASB (N=3): 연속 3프레임 입력 → 각 입력 프레임에 대응하는 히트맵 3장 출력 (MIMO 구조, 5.2절)
    - 두 방법 모두 입력 프레임 수는 설정값이고, 위는 실험에서 쓴 값이다.

- **좌표 계산:**
    - TrackNet: 히트맵 이진화 → Hough 원 검출 → 원의 중심 좌표 반환
    - WASB: 히트맵 이진화 → Blob 추출 → CoH(Center of Heatmap)로 좌표 계산. Blob 내부의 히트맵 값을 가중치로 사용하며, 히트맵 값의 합을 Confidence로 사용한다.

## 핵심 아이디어

### 1. 히트맵으로 공 위치 표현

- **기존 한계:**
    - 기존 영상 인식 방법은 형태, 색상, 크기 등 외형 특징에 의존하며, 공이 흐릿하거나 잔상이 생기면 인식 정확도가 떨어질 수 있다. (서론)
    - 비교 대상인 Archana 알고리즘도 배경 차분, 프레임 차분, 모양과 크기 조건으로 공 후보를 생성한 뒤 분류하는 방식이다. (관련 연구)
    - 히트맵 방식 자체가 기존 방법의 어떤 한계를 해결하기 위해 도입되었는지는 논문에서 구체적으로 설명하지 않는다. 히트맵을 이용한 위치 표현이 다른 연구에서도 사용되었다고 언급한다. (서론, 관련 연구)
    
- **TrackNet의 방법:**
    - **정답 히트맵:**
        - 공 중심을 기준으로 2D Gaussian 분포를 생성하고, 값의 범위를 0~255로 변환한다. 히트맵 크기는 입력 프레임과 같다. (4장)
        - 분산은 σ²=10이다. 테니스공의 평균 반지름이 약 5픽셀이라는 점을 고려해, 히트맵을 128로 이진화했을 때 공의 크기와 비슷한 영역이 남도록 설정했다. (4장)
    - **모델 출력:**
        - 마지막 층은 각 픽셀마다 0~255의 256개 클래스에 대한 확률을 출력한다. (4장, 표 II)
        - Softmax로 클래스별 확률을 계산하고, 가장 높은 확률을 가진 클래스의 인덱스를 해당 픽셀의 히트맵 값으로 사용한다. (4장)
    - **손실 함수:**
        - Cross Entropy Loss를 사용한다. 각 픽셀의 정답 히트맵 값에 해당하는 클래스만 1이고 나머지는 0인 One-hot 형태로 학습한다. (4장)
        - 즉, 픽셀마다 0~255 중 하나의 값을 맞히는 256개 클래스 분류 문제로 학습한다.

- **효과 및 실험:**
    - 히트맵 방식 자체와 다른 출력 방식(좌표 직접 예측 등)을 비교한 실험은 5장에서 확인되지 않는다.
    - 논문의 주요 비교 실험은 기존 알고리즘과 TrackNet의 성능 비교, 단일 프레임 입력(Model I)과 연속 3프레임 입력(Model II)의 성능 비교다. (5장)

### 2. 연속 프레임 입력

- **기존 한계:**
    - 프레임별 인식의 한계는 위 `해결하려는 문제`에 정리함.
    - 논문이 연속 프레임을 활용하게 된 배경은 두 가지다.
        - 연속된 프레임의 후보 위치를 궤적 모델로 연결하면 추적 성능을 개선할 수 있다는 점.
        - 여러 저화질 프레임의 정보를 결합해 영상 품질을 개선하는 고전적인 기법이 있다는 점.
    - 논문은 이러한 아이디어를 규칙 기반이 아닌 딥러닝으로 구현하고자 한다. (서론)

- **TrackNet의 방법:**
    - 입력 구성:
        - 입력 프레임 수는 네트워크의 설정값이다. 1장을 입력하면 일반적인 CNN과 같은 형태이며, 여러 장을 입력하면 시간적 움직임 패턴을 학습할 수 있다고 설명한다. (4장)
        - 입력 프레임 수를 제한 없이 늘릴 수 있는 구조(scalable)라고 설명한다. (5장)
        - 3장 입력 모델은 연속된 3프레임을 입력받아 마지막 프레임의 공 좌표를 추정한다. (5장)
        - 학습 시퀀스는 마지막 프레임이 학습 세트에 속하는 경우 해당 프레임을 기준으로 구성한다. (5장)
    
    - Model I과 Model II의 차이:
        - Model I은 입력 1장, Model II는 연속 3장을 사용한다. (4장)
        - 두 모델은 입력 프레임 수에 차이가 있으며, 이를 비교하기 위해 구현되었다. (4장, 5장)
        - 입력 프레임 수가 다르기 때문에 학습 및 테스트 세트 구성도 달라지며, 두 모델의 테스트 세트가 완전히 동일하지는 않다. (5장, 표 IV)

- **효과:**
    - 테니스 테스트셋 성능 비교 (Precision / Recall / F1): (5장, 표 V)
        - Archana(규칙 기반): 92.5 / 74.5 / 82.5
        - Model I (1장): 95.7 / 89.6 / 92.5
        - Model II (3장): 99.8 / 96.6 / 98.2
    - 위치 오차가 5픽셀을 초과하는 비율은 Model I이 4.3%, Model II가 0.1%다. (5장)
    - 가려진 공(VC3) 7장 중 Model II가 2장을 정확히 찾았다. 논문은 이를 연속 프레임이 궤적 정보를 제공한다는 근거로 제시한다. (5장)
        - 다만 표본이 7장뿐이므로 일반화하기에는 한계가 있다. (해석)
    - 추가 데이터를 사용한 Model II'의 10-fold 교차검증 결과는 Precision 95.3 / Recall 75.7 / F1 84.3이다. (초록, 5장)
        - 같은 Model II'의 70/30 분할 결과 F1 98.5와 차이가 크다.
        - 차이의 원인으로 (1) 무작위 분할에서 인접 프레임이 학습·데스트에 나뉘었을 가능성, (2) 10-fold가 다양한 코트의 추가 영상을 포함한 다른 데이터라는 점이 있다. 논문은 원인을 설명하지 않는다. (해석)
    - 따라서 Model I과 Model II의 성능 차이를 입력 프레임 수 하나의 효과로 단정하기 어렵다. 테스트 세트가 완전히 동일하지 않고, 동일 영상에서 프레임을 무작위로 분할한 실험이기 때문이다.
